# Fluxion Logistic - LogísticaAr v3.0

Sistema integral de gestión logística y ERP profesional para el transporte de carga pesada y última milla.

## 🚀 Características Principales

- **Monitor Operativo**: Seguimiento en vivo de unidades con telemetría avanzada y alertas S.O.S.
- **Módulo ERP de Presupuestos**: Cotizaciones comerciales profesionales con multimoneda y fotos de productos.
- **Gestión de Flota**: Control de legajos digitales, mantenimientos programados y auditoría de costos por KM.
- **WMS e Inventario**: Mapa de racks virtual y control de stock multi-sede.
- **App del Chofer**: Terminal móvil optimizada con captura de firmas en pantalla completa y GPS en tiempo real.
- **Inteligencia Artificial**: Optimización de rutas y análisis de mercado para prospección.

## 🛠️ Tecnologías

- **Framework**: Next.js (App Router)
- **Base de Datos y Auth**: Firebase (Firestore & Auth)
- **Styling**: Tailwind CSS + ShadCN UI
- **Generación Documental**: jsPDF (Vectorial A4)
- **IA**: Google Genkit + Gemini 2.5 Flash

## 📦 Configuración Local

1. Clona el repositorio.
2. Crea un archivo `.env` con tus credenciales de Firebase.
3. Ejecuta `npm install`.
4. Corre el entorno de desarrollo con `npm run dev`.
